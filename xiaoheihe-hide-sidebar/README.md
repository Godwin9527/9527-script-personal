# 9527小黑盒帖子页加宽

把小黑盒帖子页右侧那一整列「热门社区 / 相关资讯」去掉,让帖子正文直接铺满窗口宽度。宽度完全跟随窗口自动变化,不需要手动填数值。

## 功能

- 隐藏帖子页右侧整列:热门社区、相关资讯、侧边推广都一并去掉。
- 正文自动铺满腾出来的空间,窗口拉宽变宽、窗口收窄变窄,不需要手动设置宽度。
- 侧栏去掉后正文列宽从原来的 660px 提升到接近整个窗口宽度。
- 开关只放在脚本管理器菜单里,页面上不会新增任何按钮或悬浮控件。
- 只在帖子页(`/app/bbs/link/*` 这类页面)生效,其它页面不做任何改动。

## 实现方式

- 帖子页布局是横向 flex 两列:左列 `.list` 是正文且为弹性宽度,右列 `.cpt-right-side` 是固定 356px 的侧栏。右列固定、左列弹性,所以直接给右列 `display:none`,正文会自动吃掉空出来的空间,不需要写死左列宽度。
- 外层 `#page-bbs-link` 把总宽度锁死在 1032px,`main` 又锁死在 1300px,两处都必须解除限制,正文才能真正跟着窗口变化。
- `main` 的放宽用 `:has(#page-bbs-link)` 精确限定,只影响包含帖子布局的页面,不会波及其它页面的排版。
- 超宽屏下正文拉得太开会造成长行难读,所以留了 1600px 的上限并居中;普通窗口下正文始终铺满,这个上限用不到。
- 正文图片补 `max-width:100%`,避免原图固定宽度把页面撑出横向滚动条。
- 样式在 `document-start` 阶段注入,打开页面不会出现先窄后宽的跳动。

## 使用方法

1. 安装脚本后打开任意小黑盒帖子页。
2. 页面加载后右侧整列自动消失,正文铺满窗口宽度。
3. 想对比原版时,点脚本管理器菜单里的「隐藏右侧栏:已开启(点击关闭)」即可切回;再点一次恢复。

## 注意事项

- 关闭开关会立即恢复原版 1032px 布局,设置通过脚本管理器持久保存,刷新后仍然生效。
- 脚本只处理帖子页;首页、社区列表页等其它页面不做任何改动。
- 窗口宽度较窄时(约 1024px 以下),小黑盒自身就会收起右侧栏,脚本在这个区间只是让正文少一点边距,不会造成排版异常。
- 依赖小黑盒当前的类名(`.cpt-right-side`、`#page-bbs-link`),若网站大改版可能需要更新脚本。

## 可调参数

脚本顶部的常量可以按需调整:

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `MAX_WIDTH` | 1600 | 正文最大宽度上限(px),只影响超宽屏,普通窗口下正文始终铺满 |
| `DEFAULT_ENABLED` | true | 首次安装时是否默认开启 |

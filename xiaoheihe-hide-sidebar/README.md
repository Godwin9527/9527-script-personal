# 9527小黑盒帖子页加宽

把小黑盒右侧那一整列「热门社区 / 相关资讯」去掉,让正文直接铺满窗口宽度。宽度完全跟随窗口自动变化,不需要手动填数值。

覆盖三类页面:帖子页、社区首页、社区详情页。

## 功能

- 隐藏右侧整列:热门社区、相关资讯、侧边推广都一并去掉。
- 正文自动铺满腾出来的空间,窗口拉宽变宽、窗口收窄变窄,不需要手动设置宽度。
- 侧栏去掉后正文列宽从原来的 660px 提升到接近整个窗口宽度。
- 覆盖三类页面:
  - 帖子页 `/app/bbs/link/<id>`
  - 社区首页 `/app/bbs/home`
  - 社区详情页 `/app/topic/link/<id>`
- 开关只放在脚本管理器菜单里,页面上不会新增任何按钮或悬浮控件。
- 站点其它页面不做任何改动。

## 实现方式

- 三类页面共用同一套横向 flex 布局:左列正文是弹性宽度,右列 `.cpt-right-side` 是固定 356px 的侧栏。右列固定、左列弹性,所以直接给右列 `display:none`,正文会自动吃掉空出来的空间。
- 三处宽度限制都必须解除,正文才能真正跟着窗口变化:
  - 页面根容器 `[id^="page-"]` 锁死 1032px
  - 外层 `main` 锁死 1300px
  - 社区首页 / 社区详情页的左列还额外被限制在 660px(帖子页没有这条限制,这也是早期只有帖子页生效的原因)
- `main` 的放宽用 `:has([id^="page-"])` 精确限定,只影响包含这些页面布局的情况,不波及其它页面。
- 社区列表最后一张卡片会多出 16px 外边距,导致页面出现横向滚动条,根容器用 `overflow-x: clip` 裁掉;`clip` 不会创建滚动容器,不影响页面内 sticky 元素。
- 超宽屏下正文拉得太开会造成长行难读,所以留了 1600px 的上限并居中;普通窗口下正文始终铺满,这个上限用不到。
- 样式在 `document-start` 阶段注入,打开页面不会出现先窄后宽的跳动。

## 使用方法

1. 安装脚本后打开小黑盒的帖子页 / 社区首页 / 社区详情页。
2. 页面加载后右侧整列自动消失,正文铺满窗口宽度。
3. 想对比原版时,点脚本管理器菜单里的「隐藏右侧栏:已开启(点击关闭)」即可切回;再点一次恢复。

## 注意事项

- 关闭开关会立即恢复原版 1032px 布局,设置通过脚本管理器持久保存,刷新后仍然生效。
- 窗口宽度较窄时(约 1024px 以下),小黑盒自身就会收起右侧栏,脚本在这个区间只是让正文少一点边距,不会造成排版异常。
- 社区首页和社区详情页的正文是纵向信息流,加宽后卡片仍然是单列排布,不会变成多列。
- 依赖小黑盒当前的类名(`.cpt-right-side`、`[id^="page-"]`)与左列结构,若网站大改版可能需要更新脚本。

## 可调参数

脚本顶部的常量可以按需调整:

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `MAX_WIDTH` | 1600 | 正文最大宽度上限(px),只影响超宽屏,普通窗口下正文始终铺满 |
| `DEFAULT_ENABLED` | true | 首次安装时是否默认开启 |

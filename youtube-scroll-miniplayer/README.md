# 9527YouTube滚动小窗

在 YouTube 视频页向下滚动到评论区后，自动把正在播放的视频固定为悬浮小窗。小窗可以像普通桌面窗口一样拖动、从八方向缩放，并自动记忆位置和尺寸。

## 功能

- 向下滚动、播放器基本离开视口后自动进入小窗模式。
- 向上滚动、原播放器重新露出后自动恢复页面布局。
- 顶部抓手用于拖动小窗，松开鼠标后立即保存位置。
- 四条边与四个角提供八方向缩放，松开鼠标后立即保存尺寸。
- 双击顶部抓手可恢复默认的位置和尺寸。
- 位置和尺寸通过脚本管理器持久化，关闭浏览器或重启电脑后仍然保留。
- 支持 YouTube 普通模式与影院模式。
- 支持 YouTube 单页应用内切换视频，不会把下一条视频错误地固定在小窗位置。
- 进入浏览器整页全屏时自动退出小窗模式，避免影响全屏播放。
- 窗口尺寸变小时会自动把已保存的小窗限制在当前可视范围内。

## 操作

| 操作 | 方式 |
| --- | --- |
| 移动小窗 | 按住小窗顶部中央的抓手拖动 |
| 调整大小 | 拖动小窗左、右、上、下边缘或四个角 |
| 恢复默认 | 双击顶部抓手，或使用脚本管理器菜单中的“恢复小窗默认位置和大小” |
| 精确移动 | 聚焦顶部抓手后使用方向键，按住 Shift 可加速移动 |

## 可调参数

脚本顶部的 `CONFIG` 提供以下常用参数：

| 参数 | 说明 |
| --- | --- |
| `defaultWidth` | 首次使用时的小窗宽度 |
| `defaultMargin` | 首次使用时距离视口右下角的外边距 |
| `minWidth` / `minHeight` | 手动缩放时允许的最小尺寸 |
| `activateWhenPlayerBottom` | 原播放器底部接近视口顶部到什么程度时进入小窗 |
| `deactivateWhenPlayerBottom` | 原播放器重新露出多少高度后退出小窗 |
| `enableTheaterMode` | 是否在影院模式下启用小窗 |

## 注意事项

- 脚本固定的是 YouTube 现有的 `#player-container`，不会调用浏览器原生的画中画，因此字幕、播放进度、清晰度、音量与播放器快捷键仍然可用。
- 首次使用时默认出现在右下角；实际拖动或缩放一次后，该位置和尺寸会成为后续所有视频的默认布局。
- 如果保存的位置在当前屏幕外，脚本会自动将它限制回可视范围内。
- 暂不适配 YouTube Shorts 页面。

# 9527哔哩哔哩稍后再看快捷键删除

在哔哩哔哩“稍后再看”页面，通过自定义快捷键删除当前正在播放的视频，并交由 B 站列表自身的逻辑自动切换下一项。

## 功能

- 快捷键默认留空，安装后不会触发任何按键。
- 可在脚本菜单中打开设置面板，直接录制组合键。
- 支持修改或清除快捷键。
- 删除时定位当前视频对应的列表项，不误删其他视频。
- 不直接调用删除接口，也不接管播放器，删除后仍沿用 B 站原生切换逻辑。

## 使用方法

1. 安装脚本后，打开哔哩哔哩“稍后再看”页面。
2. 在脚本管理器中点击“设置稍后再看删除快捷键”。
3. 点击“录制快捷键”，按下需要的按键或组合键。
4. 在“稍后再看”页面按已设置的快捷键，删除当前播放视频。

例如可以录制小键盘加号 `+`，即脚本管理器识别到的 `NumpadAdd`。

## 注意事项

- 默认不设置快捷键，必须手动录制后才会生效。
- B 站处于随机播放模式时会禁用删除；此时快捷键无法删除视频。
- 多分 P 视频会按 B 站原生行为删除整个投稿。
- 如果当前视频是列表最后一项，B 站原生逻辑可能会切换到上一项。
- 页面需要能识别地址栏中的当前视频编号 `bvid`。

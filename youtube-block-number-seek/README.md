# 9527数字键快捷键拦截

按网站名单拦截主键盘 `0-9` 与小键盘 `0-9`，避免网页自带的数字键快捷键抢占按键，同时保留搜索框、评论框等位置正常输入数字的能力。默认在 `youtube.com` 生效，用于禁用 YouTube 的按数字跳转到视频百分比位置功能。

## 功能

- 在暴力猴脚本菜单中打开“数字键拦截设置”，随时管理网站名单。
- 支持一键加入或移出当前网站，也可以手动输入域名。
- 支持两种拦截模式：
  - `仅名单内拦截`：只拦截名单内的网站。
  - `仅名单外拦截`：名单作为例外，拦截名单外的所有网站。
- 域名规则包含子域名，例如 `youtube.com` 会匹配 `www.youtube.com` 和 `m.youtube.com`。
- 一键加入 `www.example.com` 时，会自动规范化为 `example.com`。
- 支持普通域名、子域名、`localhost` 和 IP 地址。
- 默认拦截主键盘与小键盘数字键，`Ctrl`、`Alt`、`Meta` 组合键正常放行。
- 焦点位于输入框、文本域、下拉框、可编辑区域时，不拦截数字键。
- 默认使用兼容拦截策略，避免影响其他扩展的页面级数字键快捷键。

## 使用方法

1. 安装或更新脚本后，打开需要屏蔽数字键快捷键的网站。
2. 在暴力猴脚本管理器中点击“数字键拦截设置”。
3. 点击“加入当前网站”，或手动输入域名后点击“添加”。
4. 根据需要在“仅名单内拦截”和“仅名单外拦截”之间切换。

默认配置为“仅名单内拦截”，并预置 `youtube.com`。升级后 YouTube 的原有拦截行为保持不变。

## 模式说明

| 模式 | 行为 |
| --- | --- |
| 仅名单内拦截 | 名单中的网站拦截，名单外放行 |
| 仅名单外拦截 | 名单作为例外放行，名单外的网站拦截 |

切换到“仅名单外拦截”后，同一份名单的语义会反转。例如名单里的 `youtube.com` 会变成放行对象。设置面板会显示当前网站是“当前拦截”还是“当前放行”。

## 严格拦截

设置面板底部提供默认关闭的“严格拦截”开关。

- 关闭时使用 `stopPropagation()`，优先兼容其他页面级扩展快捷键。
- 开启时使用 `stopImmediatePropagation()`，可以拦截同一 `window` 层继续传播的网页监听器，但可能同时影响挂在页面 `window` 层的扩展快捷键。
- 只有普通模式下仍无法拦截某个网站的快捷键时，才建议临时开启。

## 拦截范围与限制

- 仅拦截 `keydown`，不拦截 `keyup` 或 `keypress`。
- 带 `Ctrl`、`Alt` 或 `Meta` 的组合键不会拦截。
- 第一版规则只做域名级匹配，不支持路径、查询参数、端口或通配符。
- 脚本会注入同源及跨域 iframe，因此现有页面内嵌 YouTube 播放器的拦截能力保留。
- 兼容模式无法阻止网页伪装成更早注册的 `window` 捕获监听器；这类特殊情况需要使用严格拦截。

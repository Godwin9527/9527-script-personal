# 9527脚本自用

个人自用的用户脚本(UserScript)集合,使用暴力猴 / Tampermonkey 等脚本管理器安装。

## 脚本列表

### B站9527助手

基于 [MR哔哩哔哩助手](https://github.com/iMortRex) 改造的个人自用版本。

- 功能:自动宽屏模式 / 自定义布局 / 智能连播 / 网页全屏 等
- 原作者:Mort Rex (MIT)
- 本仓库版本:独立改造版,修改了脚本名称、命名空间、版本号与更新地址,与原脚本的设置存储完全隔离,互不影响。

#### 安装

点击下方链接,在脚本管理器(暴力猴 / Tampermonkey / Greasemonkey)中直接安装:

```
https://raw.githubusercontent.com/Godwin9527/9527-script-personal/main/bilibili-9527-helper.user.js
```

#### 文件说明

| 文件 | 说明 |
| --- | --- |
| `bilibili-9527-helper.user.js` | 主脚本(安装用) |
| `bilibili-9527-helper.meta.js` | 元数据(脚本管理器检查更新用) |
| `原始脚本-备份.txt` | 改造前的原始脚本备份 |

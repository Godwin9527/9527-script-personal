# 9527脚本自用

个人自用的用户脚本(UserScript)集合,适用暴力猴 / Tampermonkey 等脚本管理器。

## 脚本列表

| 脚本 | 说明 | 安装链接 |
| --- | --- | --- |
| [B站9527助手](./bilibili-9527-helper) | 自动宽屏 / 自定义布局 / 智能连播 等 | [安装](https://raw.githubusercontent.com/Godwin9527/9527-script-personal/main/bilibili-9527-helper/bilibili-9527-helper.user.js) |
| [B站稍后再看快捷键删除](./bilibili-watchlater-delete-hotkey) | 自定义快捷键删除当前视频并自动切换下一项 | [安装](https://raw.githubusercontent.com/Godwin9527/9527-script-personal/main/bilibili-watchlater-delete-hotkey/bilibili-watchlater-delete-hotkey.user.js) |
| [Reddit图集增强](./reddit-gallery-loop) | 放大图集切换箭头（悬停显示 / 大小可调）/ 首尾循环浏览 | [安装](https://raw.githubusercontent.com/Godwin9527/9527-script-personal/main/reddit-gallery-loop/reddit-gallery-loop.user.js) |

每个脚本独立存放在自己的文件夹下,详见各文件夹内的 README。

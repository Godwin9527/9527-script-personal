# 9527哔哩哔哩CC字幕快捷键

用键盘快捷键开关哔哩哔哩的 CC 字幕。直接操作 B 站自己的字幕，不另画字幕层，所以字幕的字体、位置、样式都跟 B 站原生完全一致。

## 功能

- 一个动作：开关 CC 字幕，不含其他快捷键。
- 快捷键可自定义，默认为 `Shift` + `C`。
- 字幕语言偏好可选：跟随 B 站播放器设置 / 中文 / 英文 / 日文 / 自定义语言代码。
- 「优先人工字幕」可关：同一语言下先找人工字幕，再退回 AI 字幕。
- 匹配不到偏好语言时，依次回退到 AI 字幕、包含该语言的任意字幕、第一个可选字幕。
- **进入视频时自动关闭字幕**（默认开启），解决 B 站恢复上次状态导致 AI 字幕自动打开的问题。
- 字幕面板未渲染时自动唤醒，不需要先手动点一次字幕按钮。

## 自动关闭字幕

B 站会记住上次的字幕状态，常见表现是新进视频 AI 字幕自己就开了。

勾选「进入视频时自动关闭字幕」后，每次进入视频页或切换视频，脚本会在 **20 秒窗口**内每 0.6 秒检查一次状态，一旦发现字幕被打开就点关闭项；连续 3 次点不动就停止重试，不会卡在死循环里。

三条让位规则，避免和你的操作打架：

| 情况 | 行为 |
| --- | --- |
| 窗口内按过本脚本的快捷键 | 本轮观察立即结束，不再自动关 |
| 窗口内用鼠标点过字幕按钮或语言项 | 同上 |
| 字幕本来就是关的 | 什么都不做，安静等到窗口结束 |

不想要这个行为就在设置面板里取消勾选。

## 原理

1. `document-start` 注册按键监听，`capture` 阶段拦截并阻止继续传递。
2. 按键触发后先看字幕面板在不在（`.bpx-player-ctrl-subtitle-close-switch`）；不在就先 hover、再点一次字幕按钮把面板唤出来。
3. 按 `close-switch` 是否带 `bpx-state-active` 判断当前是开是关。
4. 要开：从 `.bpx-player-ctrl-subtitle-language-item` 里按语言偏好挑一项点击。
5. 要关：点关闭开关。
6. 每次点击后回读状态确认真的生效，没生效就换点击方式重试（纯 `click` → 完整指针事件序列 → 点内部文本节点），最多 6 轮。
7. 全部失败时把完整现场信息复制到剪贴板，便于排查。

早期版本曾尝试自行拉取字幕数据并绘制字幕层，现已放弃——B 站原生字幕本身可用，没必要重复实现一套。

## 使用方法

1. 安装脚本后打开任意 B 站视频页。
2. 点击脚本管理器图标，选择「设置 CC 字幕快捷键」。
3. 点「录制」，按下需要的组合键（`Esc` 取消录制），再点「保存」。
4. 在视频页按该组合键即可开关字幕。

脚本菜单里还有：

| 菜单项 | 用途 |
| --- | --- |
| 切换一次 CC 字幕（调试） | 不用键盘直接触发，便于排查 |
| 诊断：显示按键信息（开/关） | 按一次键就在左下角显示按键匹配情况 |
| 复制诊断信息到剪贴板 | 版本、面板状态、语言项、字幕层等现场信息 |

## 注意事项

- **如果同时启用了 Bilibili Evolved 的「快捷键扩展 - 开关 CC 字幕」并绑定了同一个键，会触发两次，表现为按键无效。请把 BE 里该动作的自定义按键清空，或禁用该插件。**
- 需要登录态才能拿到完整的字幕语言列表。
- 只处理主字幕的语言选择，不涉及次字幕 / 双语字幕。
- 依赖 B 站播放器的 DOM 结构（`.bpx-player-ctrl-subtitle-*`），B 站大改版时需要同步更新选择器。

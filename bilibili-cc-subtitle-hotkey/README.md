# 9527哔哩哔哩CC字幕快捷键

在哔哩哔哩视频页用键盘快捷键开关 CC 字幕，独立实现，不依赖 Bilibili Evolved 或其他脚本。

起因：B 站改版后字幕面板按需渲染，且 Bilibili Evolved 的「快捷键扩展 - 开关 CC 字幕」未处理控件尚未渲染的情况，导致刚打开视频时按快捷键没有反应，需要先手动点一次控制栏的字幕按钮。本脚本在触发前会先唤醒并等待字幕面板，因此不受该时序问题影响。

## 功能

- 一个动作：开关 CC 字幕，不含其他快捷键。
- 快捷键可自定义，默认为 `Shift` + `C`。
- 字幕语言偏好可选：跟随 B 站播放器设置 / 中文 / 英文 / 日文 / 自定义语言代码。
- 可开关「优先人工字幕」：同一语言下先找人工字幕，再退回 AI 字幕。
- 匹配不到偏好语言时，依次回退到 AI 字幕、包含该语言的任意字幕、第一个可选字幕。
- 提示默认沿用 B 站自己的提示；找不到字幕控件或没有可选字幕时，在左下角显示提示。
- 优先走**播放器内部字幕接口**（`player.__core().subtitleStore`），不依赖点击，因此不受「合成点击不被识别」影响；内部接口不可用时才回退到界面点击，并校验状态、失败重试。

## 使用方法

1. 安装脚本后打开任意 B 站视频页。
2. 点击脚本管理器图标，选择「设置 CC 字幕快捷键」。
3. 点「录制」，按下需要的组合键（`Esc` 取消录制），再点「保存」。
4. 在视频页按该组合键即可开关字幕。

也可以在脚本菜单里用「切换一次 CC 字幕（调试）」手动触发一次，便于排查。如果仍然切换不了，点菜单「复制诊断信息到剪贴板」，把复制到的内容发出去即可定位问题。

## 注意事项

- **如果同时启用了 Bilibili Evolved 的「快捷键扩展 - 开关 CC 字幕」并绑定了同一个键，会触发两次，表现为按键无效。请把 BE 里该动作的自定义按键清空，或禁用该插件。**
- 脚本在 `document-start` 注册按键监听，并阻止事件继续传递，因此比页面内其他快捷键逻辑更早拿到按键。
- 找不到字幕面板时，脚本会模拟点击控制栏的字幕按钮来唤醒面板，此时可能看到面板闪一下，属于正常现象。
- 只处理主字幕的语言选择，不涉及次字幕 / 双语字幕。
- 字幕列表来自页面自身渲染，脚本不调用任何 B 站接口，也不需要登录态。

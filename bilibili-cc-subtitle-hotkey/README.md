# 9527哔哩哔哩CC字幕快捷键

在哔哩哔哩视频页用键盘快捷键开关 CC 字幕，完全独立实现，不依赖 Bilibili Evolved，也不依赖 B 站自己的字幕按钮。

## 为什么不用 B 站的字幕按钮

试过很多轮，结论如下：

- B 站播放器控制栏只响应真实用户交互。脚本合成的 `click` / `pointerdown` 事件 `isTrusted === false`，打在字幕按钮或语言项上，面板不会初始化，语言也不会切换。
- 实测表现：新打开视频页直接按快捷键毫无反应；必须先手动点一次字幕按钮，之后合成点击才「看起来」生效。
- `player` 实例上没有 `setSubtitle` 一类 setter（只有 `addSubtitle`、`reloadAccess`），`__core()` 也不再暴露 `subtitleStore`，播放器没给脚本留字幕开关。
- 面板在未初始化时是隐藏的（`rect=0x0`），语言项不可见，点它自然无效。

所以 2.0.0 起换成完全自主的方案：脚本自己拉字幕数据、自己画字幕层。

## 功能

- 一个动作：开关 CC 字幕，不含其他快捷键。
- 快捷键可自定义，默认为 `Shift` + `C`。
- 字幕语言偏好可选：跟随 B 站播放器设置 / 中文 / 英文 / 日文 / 自定义语言代码。
- 可开关「优先人工字幕」：同一语言下先找人工字幕，再退回 AI 字幕。
- 匹配不到偏好语言时，依次回退到 AI 字幕、包含该语言的任意字幕、第一个可选字幕。
- 打开页面立刻可用：不依赖 B 站字幕面板是否初始化，不需要先点字幕按钮。
- 字幕由脚本渲染，只显示一条主字幕，不涉及次字幕 / 双语字幕。

## 字幕位置与样式（2.1.0）

设置面板里新增「字幕位置」和「字幕样式」两组，面板顶部带实时预览，调整时立刻能看到效果，点保存后立即应用到正在显示的字幕。

| 项 | 可选范围 | 默认 |
| --- | --- | --- |
| 垂直位置 | 距播放器底部 2% ~ 45% | 9%（与 B 站原生接近） |
| 水平对齐 | 居中 / 靠左 / 靠右 | 居中 |
| 字号 | 50% ~ 250%（基准为容器高度的 5.2%） | 100% |
| 字体 | 系统黑体 / 思源黑体 / 宋体 | 系统黑体 |
| 文字颜色 | 取色器 + 白 / 黄 / 浅蓝 / 浅绿 / 粉五个预设 | 白色 |
| 描边 | 无 / 细 / 中 / 粗 | 中 |
| 背景框 | 0% ~ 100% 不透明度 | 0%（纯文字） |
| 行高 | 1.05 ~ 2.00 | 1.35 |
| 加粗 | 开 / 关 | 开 |

字号会跟随播放器尺寸自适应：网页全屏、全屏、调整窗口大小都会重新计算。`恢复默认` 按钮可把以上各项一键还原（仍需点保存）。

## 实现方式

1. 从页面状态（`window.__INITIAL_STATE__`）取 `bvid` / `cid` / `ep_id`，多 P 时以 URL 的 `p` 为准，必要时用 `/x/web-interface/view` 兜底。
2. 调 `/x/player/v2` 取当前视频的字幕列表，按语言偏好挑一条。
3. 拉字幕 JSON，解析成按时间排序的 cue 列表，按 `cid` 缓存。
4. 在播放器容器内叠一层自绘字幕，用 `requestAnimationFrame` 跟随 `video.currentTime`，切换、拖动进度都会同步。
5. 自绘字幕显示期间注入一条 CSS 隐藏 B 站原生字幕层，避免重影；关闭时移除该 CSS。
6. 切换视频（SPA 路由变化）时自动重置状态，下次按快捷键重新拉当前视频的字幕。

## 使用方法

1. 安装脚本后打开任意 B 站视频页。
2. 点击脚本管理器图标，选择「设置 CC 字幕快捷键」。
3. 点「录制」，按下需要的组合键（`Esc` 取消录制），再点「保存」。
4. 在视频页按该组合键即可显示 / 隐藏字幕。

脚本菜单里还有：

- 「切换一次 CC 字幕」：不用键盘直接触发，便于排查。
- 「复制诊断信息到剪贴板」：版本、当前 `cid`、字幕条数、最近一次错误等。
- 「清空字幕缓存」：改了语言偏好或字幕没更新时用。

## 注意事项

- **如果同时启用了 Bilibili Evolved 的「快捷键扩展 - 开关 CC 字幕」并绑定了同一个键，会触发两次，表现为按键无效。请把 BE 里该动作的自定义按键清空，或禁用该插件。**
- 需要登录态：B 站的字幕接口对未登录用户返回空列表。
- 只处理主字幕的语言选择，不涉及次字幕 / 双语字幕。
- 脚本在 `document-start` 注册按键监听，并阻止事件继续传递，因此比页面内其他快捷键逻辑更早拿到按键。
- 字幕数据来自 B 站接口（`/x/player/v2`）与字幕 CDN，接口结构变化时需要同步调整选择逻辑。

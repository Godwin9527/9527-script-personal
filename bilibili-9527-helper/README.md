# B站9527助手

基于 [MR哔哩哔哩助手](https://github.com/iMortRex) 改造的个人自用版本。

## 功能

自动宽屏模式 / 自定义布局 / 智能连播 / 网页全屏 / 隐藏无关元素 等。

## 说明

- 原作者:Mort Rex (MIT)
- 本版本为独立改造版,修改了脚本名称、命名空间、版本号与更新地址,与原脚本的设置存储完全隔离,互不影响。
- v1.0.1: 修复网页全屏模式偶发不生效(收紧就绪判定 + 异常自愈重试)。

## 安装

点击下方链接,在脚本管理器中直接安装:

# 9527字幕悬浮球助手

在 MissAV / Jable 的播放页挂一个可拖拽的「字幕」悬浮球，点开就能加载本地 SRT、在线搜字幕、自动加载、一键换字幕、调字幕样式。

## 功能

- **页面级浮层**：字幕画在网页最上层，按视频的实际位置对齐，不受播放器容器裁剪、层级、重建影响。
- **自动加载**：打开视频后自动按番号搜一次字幕，随机加载其中一条。面板上有开关，默认开启。
- **更换字幕**：面板「更换字幕」按钮，从同一番号的候选里随机换一条，并排除当前正在用的那条；没有缓存列表时先现搜。
- **本地字幕**：选择 `.srt` 文件即可加载，支持 `HH:MM:SS,ms` 与 `.` 分隔毫秒两种格式。
- **在线字幕**：两个来源
  - `在线搜索`：调迅雷公开字幕接口，结果以列表展示，点一条即加载
  - `站点搜索`：按当前视频番号跳转 Subtitlecat
- **字幕样式**：位置（距底部 0%–90%）、大小（12–72px）、颜色三项实时生效。
- **字幕偏移**：整体提前 / 延后若干秒，改动立即重算时间轴；负偏移时落在地平线之前的字幕保留可见部分，不会整条消失。
- **悬浮球**：可拖拽到任意位置，位置写入 localStorage，下次打开还在原处；面板按剩余空间自动决定向上或向下展开。

本脚本**不含**播放倍速、快进、倒退等快捷键，只做字幕。

## 实现方式

- **页面级字幕浮层**：字幕**不挂在播放器容器里**，而是 `position: fixed` 挂在 `body` 上，每 100ms 按 `<video>` 的 `getBoundingClientRect()` 换算位置。这样播放器容器的 `overflow: hidden`、`transform`、层级、裁剪、重建都不会让字幕消失。视频滚出视野时自动隐藏。
- **全屏适配**：进入全屏时只有全屏元素的子树会被渲染，所以浮层会临时挂进全屏元素并改用 `absolute` 定位（按全屏元素的坐标换算），退出后自动回 `body`。
- **播放器桥接**：页面播放器与脚本运行在不同 JS 上下文，脚本注入一段 `script` 桥接代码，监听 `player` / `plyr` / `videojs` 实例与 `<video>` 媒体事件，把 `currentTime` / `paused` / `seeking` 通过 `data-*` 属性加自定义事件回传。仅作为读时间的兜底。
- **独立渲染循环**：字幕显示不依赖 `timeupdate` 事件，由 100ms 定时器主动渲染。视频暂停、尚未开始播放、或站点播放器不派发标准事件时，字幕照样出得来。
- **多 video 纠偏**：页面里有多个 `<video>`（广告、预览、站点重建播放器）时，优先选择正在播放的那个，并在 1.5 秒节流下自动把事件绑定迁到它上面，避免读到一直停在 0 秒的旧元素。
- **时间来源**：优先读取真实 `<video>` 的 `currentTime`（`readyState > 0` 时可信）；读不到才退回桥接状态，且要求桥接数据在 3 秒内更新过。
- **请求防竞态**：每次加载字幕带一个递增序号，快速连点「更换字幕」时，先发后到的旧响应会被丢弃。
- **悬浮球拖拽**：Pointer Events，位移超过 4px 判定为拖拽并吞掉随后的 click，避免拖完误触展开面板。

## 使用方法

1. 打开 MissAV 或 Jable 的播放页，右下角出现「字幕」悬浮球（初次在左下）。
2. 等几秒，脚本会自动搜并加载一条字幕；不满意就点悬浮球展开面板，按「更换字幕」。
3. 也可以点 `本地字幕` 自己选 SRT，或 `在线搜索` 从列表里挑。
4. 按需调位置 / 大小 / 颜色 / 偏移，点 `保存设置` 持久化。
5. 点 `收起面板` 回到悬浮球状态。

## 注意事项

- 加载字幕后，浮层会先显示一条 `字幕已就绪 · N 条 · 当前时间` 的短提示（约 2.6 秒）。**能看见这行字，就说明浮层本身是正常的**；看不见则是播放器没被识别到，提示会写明「未找到播放器」。
- 字幕加载后 25 秒、视频在播却一条都没命中过，会提示「可能是时间轴不匹配」，此时用面板里的「字幕偏移」微调。
- 自动加载每个番号只尝试一次；手动点「清空字幕」后，本页不再自动加载，避免刚清掉又被塞回来。
- 在线搜索依赖迅雷的公开接口，接口变更或限流时可能取不到结果；`站点搜索` 只是站外跳转，需要能访问 subtitlecat。
- 跨域请求通过 `GM.xmlHttpRequest` 发出，脚本管理器中需放行 `@connect` 里声明的域名。
- 番号解析基于 URL 路径正则，非标准路径可能取不到番号，此时自动加载和在线搜索会跳过。

## 可调参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `FLOATING_UI_GAP` | 8 | 悬浮球与面板 / 字幕列表之间的间距（px） |
| `FLOATING_BUTTON_POSITION_KEY` | `missavFloatingButtonPosition` | 悬浮球位置在 localStorage 里的键名 |
| 渲染间隔 | 100ms | `startSubtitleRenderLoop` 内的定时器周期，同时负责跟随滚动重新定位 |
| 自动加载延迟 | 1500ms | 绑定播放器后多久开始自动搜字幕 |
| 桥接状态有效期 | 3000ms | 超过这个时间未更新就判定桥接数据过期 |
| 浮层层级 | 2147483000 | `.custom-subtitle` 的 `z-index`，压过站点所有面板与控件 |

## 排查记录：为什么以前会「提示成功但没字幕」

1. 加载成功后只清空了字幕轨道，没有主动渲染一次，完全靠 `<video>` 的 `timeupdate` 触发。视频暂停或还没开始播时事件不触发，字幕就一直不出现——但 toast 已经提示「加载成功」。
2. 字幕节点挂在播放器容器内部，容器的 `overflow: hidden` / `transform` / 层级会把节点裁掉或盖住；站点重建播放器后旧节点还会随容器移出文档，之后所有文本都写进了游离节点。
3. 是否使用桥接时间只由「桥接是否活着」决定，没有时效判断；桥接绑定到错误 media 时，时间轴会整体错位。
4. 页面存在多个 `<video>` 时，读时间的那个可能是一直停在 0 秒的广告或预览元素，于是永远匹配不到字幕条目。

1.5.0 解决第 1、3 条；1.6.0 用「页面级固定浮层 + 全屏挂载切换 + 优先选播放中的 video」从结构上消除第 2、4 条。
